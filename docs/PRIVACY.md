# 隐私与凭据

## 仓库和发布包

公开内容只包含源码、合成测试、安装脚本、公开文档、界面资源和依赖锁文件。以下内容保留在本机，不进入 Git 或 Release：

- 学校账号密码、Cookie、CAS ticket、业务 token、DPAPI 文件与状态目录。
- 本人课程、交易、报名、预约、申请等原始业务响应。
- 研究原始记录、HAR、截图中的个人内容、浏览器 profile、调试工具和本机缓存。
- 本地客户端配置、个人文件系统路径、会话标识与账户哈希。

README 界面图使用合成状态与通用示例路径重新生成。测试用账号、密码、token 和业务条目都是合成数据；不代表可用于学校登录的凭据。

## 运行时

密码由用户在本机设置页或隐藏输入 CLI 提供，只提交到校验 TLS 的官方 CAS HTTPS 登录地址。它保存在当前 Windows 用户的 DPAPI 密文里，不作为普通 MCP 参数、命令行参数、环境变量或聊天内容。

共同 CAS 登录资料与各系统业务会话分开；Cookie 保留作用域和安全属性。更换或清除凭据后，旧认证结果不能迟到写回。余额优先使用本地统一账号的学号；只有从未配置统一账号的余额单独安装保留独立学号模式。余额接口不接收密码或 CAS 会话。清除统一凭据后不会退回旧学号。

设置页只监听 `127.0.0.1`，短期启动授权、HttpOnly/SameSite Cookie、Origin/Host/CSRF 校验和 CSP 保护页面访问，资源本地提供。该设计不防御已经能以同一 Windows 用户身份执行代码的恶意程序。

## 使用 AI 客户端

账号凭据不会进入 MCP 对话，但**查询返回的课程、活动、成绩、申请、预约或电量信息会交给你正在使用的 AI 客户端**。使用前应了解该客户端及其模型服务的数据处理方式。工具会尽量移除不必要的身份字段、内部 ID 和私密详情链接，不能把“本地凭据加密”理解成“查询内容完全不离开电脑”。

## 唐岛湾剩余电量

电量查询不需要账号，也没有默认宿舍、账户设置、历史、缓存或“上次查询”。

- 楼号/房间号只作为**当前 MCP 调用**的参数，并只回显在本次结果/候选中；项目不把它们写入设置、状态目录、日志、遥测、缓存、会话、回执或测试 fixture。
- 缺楼号或房间号时不调用工具；不从账号、旧聊天、其他房间、默认宿舍或历史猜测。单次只查一间，不枚举、不批量试号。
- 工具不接受任意 URL、header、cookie、账号、校区或保存目标；请求固定到学校唐岛湾电费表单。
- 学校端点是 HTTP，楼号/房间号在传输中不受 TLS 保护。工具不通过代理、关闭证书校验或跟随重定向来扩展其他路线。
- 认证跳转、网络错误、超时、HTTP 错误或页面结构变化返回明确错误，不会变成 0 度；异常不回显原始请求 URL/body。
- MCP 客户端和宿主聊天可能按自己的策略记录工具参数；项目本身不持久化，但不能控制外部宿主的留存。
- 测试只使用合成楼号/房间号和合成 HTML/HTTP fixture；2026-11-02 对公开表单做了 GET 以核对楼号目录，并用合成房间号做了一次无结果结构探测，没有读取任何真实房间的剩余电量。

## 发布前审计

项目提供 `scripts/audit_release.py`，检查 Git 跟踪文件及发布归档是否含受排除的本机内容、敏感路径或明显凭据模式。发布流程还运行独立密钥扫描和压缩包清单复核；审计不访问或解密任何用户的真实凭据。
