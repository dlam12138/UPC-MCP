# e站通检索修复说明

旧实现始终使用匿名目录，遗漏登录后才可见的事项，包括“本科生请销假”。同一网站的匿名目录和登录目录具有不同的可见范围，不需要切换到其他平台修复。

## 修复行为

- 已保存账号时，检索该账号可见的完整目录，再本地匹配关键词、分页。
- 无可用账号时可检索公开目录，但明确返回 `public_catalog_only`、覆盖范围和下一步提示；匿名未命中不能说明学校没有该事项。
- 指南复用相同账号的业务会话；仅读取官方详情，不进入申请表单或附件。
- 文件夹与事项可能共用数值 ID；文件夹不会作为可打开的事项返回，目录元数据会说明排除数量。
- 本人待办与本人在办申请分开查询，支持分页；`complete_for_page` 与 `complete_for_scope` 区分本页和整个筛选范围。
- 网络、解析和服务端错误不会伪装成完整空结果；清除、换绑后丢弃迟到结果。

## 验证与限制

测试使用合成账号与脱敏目录形状。一次正常登录会话下的只读验收已确认：登录目录包含目标事项，检索命中、指南可读，本人待办和在办申请列表可读。

目录完整仅指当前来源、当前账号的可见范围，不代表所有身份或全校所有系统。`identity_verified=false` 继续如实保留。不包含申请提交、审批、撤回、标记已读或其他事项交互。

原始截图、浏览器资料、个人申请内容、会话和认证证据均不在仓库或发布包中。版本与升级步骤见 [更新日志](../CHANGELOG.md) 和 [配置指南](CONFIGURATION.md)。
